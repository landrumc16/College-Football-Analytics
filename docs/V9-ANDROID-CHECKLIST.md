# V9 Physical Android Checklist (Owner)

Use Chrome on your Android phone. Record the phone model, Android version and Chrome version. Emulated results in
`docs/V9-INDEPENDENT-ACCEPTANCE.md` are not physical-device evidence; only this checklist is.

Open the V9 review preview (or production after an approved release), then work top to bottom. Mark each line Pass,
Fail (with a screenshot) or Not Tested.

## Navigation and layout
- [ ] The bottom bar shows **Home, Rankings, Teams, Playoffs, Research**, and every tab opens.
- [ ] No page scrolls sideways (wide tables may scroll inside their own box only).
- [ ] Text stays readable at your normal font size, and still fits when Android's font size is set to its largest.

## Favorites
- [ ] Home, then **Edit Teams**, then **+ Add Team**: type `Texas Tech` and tap **Save Team**. Texas Tech appears under My Teams.
- [ ] Teams: choose **Baylor**. Return to Home: My Teams still shows Texas Tech.
- [ ] Close Chrome completely and reopen. Texas Tech is still saved.

## Key journeys
- [ ] Rankings: change **Evaluation** to *Current Playing Level · Last Three*, search Texas Tech, and open the list. A value is shown.
- [ ] Teams: open **Team Trajectory**. It says one observation cannot establish a trend.
- [ ] Teams, then Compare & What If: Texas Tech vs Baylor at a neutral site shows a projected winner and percentages.
- [ ] Teams, then Model Projections: switch Compare / Standard / Momentum.
- [ ] Research: open **Three-Model Prediction Accountability**, then **Probability Calibration**. Official shows game counts; Standard shows no invented percentages.
- [ ] Research, then Market Intelligence opens the market tools.

## Playoffs what-if
- [ ] Playoffs, then **Explore Scenarios**: pick *W13: TCU at Texas Tech* and choose TCU as the winner. Texas Tech's playoff odds change.
- [ ] **Reset to Baseline** restores the original table.

## Touch and keyboard
- [ ] Every button, dropdown and "What Do These Numbers Mean?" control is easy to tap without hitting a neighbour.
- [ ] Wide tables scroll sideways with a finger.

## Installed app and offline
- [ ] Chrome menu, then **Add to Home screen / Install app**. The icon appears and the app opens full-screen.
- [ ] Turn on airplane mode and reopen the app. It shows the "You are offline" page, not stale scores.
- [ ] Turn airplane mode off and refresh. Current data returns.
- [ ] After a new release, an **App Update Available** notice appears; **Reload App** shows the new version.
