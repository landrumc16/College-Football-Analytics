# College Football Analytics — Version 3.4.2 Roadmap
## Theme: This Week, Personalization & Usability
Status: COMPLETE — accepted and released November 5–6, 2026; see docs/V3.4.2-RELEASE.md and GitHub Actions run 42169215432
Branch: `v3.4.2-development`
Baseline: existing production 3.4.1; preserve its models, data feeds, PWA and branding.

## Definition of Done
Version 3.4.2 is finished only when:
1. **This Week** is the default landing page and first navigation item; **Rankings** is second.
2. The homepage gives a concise, mobile-first overview of favorite teams, featured upcoming games, upset watch, competitive games and playoff picture, with redundant bottom-of-home Rankings/CFP navigation links removed.
3. Users can choose up to **three stationary favorite teams** using existing team-name search/autocomplete; preferences persist locally without accounts. Cards show available rank, record, next opponent and model win probability. Missing values are labeled, never invented.
4. This Week derives its week and completed/upcoming state from the published schedule/report, not hardcoded calendar dates. Stale or demonstration data remains clearly identified.
5. Every prediction has an accessible **Why this pick?** explanation using only existing supported model inputs; do not fabricate scouting factors.
6. Users can share a game prediction via native share or clipboard fallback, with a clear data-as-of label.
7. **CFP Forecast** displays our existing-model Top 25, a separately sourced official CFP Top 25 (when published), a side-by-side rank comparison with correct differences and unmatched-team handling, projected 12-team field/bracket, bubble, and meaningful games. Official rankings must have a publication/as-of date; never substitute AP/Coaches or model ranks for official CFP ranks. Show verified movement only where archived snapshots support it.
8. Two-team comparison uses the existing matchup simulator and remains consistent with its venue logic.
9. Cross-links and back navigation work from team, schedule, prediction, playoff and ranking views, on mobile and desktop.
10. Existing rankings, AP/Coaches comparisons, predictions, conferences, CFP, schedule, research, team autocomplete, FBS/FCS policy, analytics accuracy and PWA remain functional.
11. Accessibility: keyboard navigation, semantic controls, no automatic motion, readable mobile layout and graceful empty/loading/offline states.
12. Typecheck/build and existing automated tests pass; new behavior has focused regression coverage; GitHub Pages deployment is verified from `main`; release notes and closeout are committed.

## Guardrails
- Karpathy principles: understand existing code, smallest coherent change, reuse before building, no parallel data/model pipelines.
- Ship in large verified passes; avoid cosmetic churn and repeated audits.
- No push notifications, live play-by-play, user accounts, backend favorites or speculative model features in this release.
- Do not represent historical/demo data as live.

## Final V3.4.2 refinements — approved November 2026

### Pass 1: Homepage and personalization
- Keep This Week as the landing view and Rankings second in navigation.
- Retain My Teams (up to three saved favorites), Featured Games, and Upset Watch.
- **Replace homepage Playoff Watch with Games That Matter**: select scheduled, not completed, games using existing rankings, model probabilities, conference context, and proximity to the playoff cutoff. Provide concise, evidence-grounded explanations; do not assert quantified rank changes without a model supporting them.
- Remove the homepage **Full Rankings** heading, **View Rankings**, and **View CFP Forecast** links. Existing primary navigation remains available.
- Preserve short, cohesive dark mobile cards, meaningful empty states, and explicit source freshness.

### Pass 2: CFP Forecast page
- Present **Our Top 25** from the existing rankings model, without introducing a separate CFP ranking algorithm.
- Present **Official CFP Top 25** from a verified committee source with season, release date, and data-as-of. If no official list is available for that season/week, show an honest unavailable state, not fabricated data.
- Provide a comparison by normalized team identity: our rank, official rank, and delta (official minus ours, with a clear sign legend); distinguish unranked from missing data and handle either Top 25-only list membership.
- Keep **projected 12-team playoff field/bracket** separate from Top 25 rankings, accounting for the applicable season's automatic-qualification/seeding rules.
- Show **bubble teams** and **Games That Matter**, explaining the supported evidence. Historical committee movement and model-versus-committee accuracy appear only where dated historical snapshots exist.

### Pass 3: User journeys and safeguards
- Verify add/change/remove favorites (0–3), autocomplete, local persistence after reload, and the compact responsive layout.
- Verify model-grounded Why This Pick?, native share/clipboard fallback with data date, venue-aware head-to-head comparisons, ranking/poll pages, back navigation, keyboard controls, offline/empty states, and no fabricated or mislabeled live data.
- Preserve prediction engine, AP/Coaches comparison, conference analytics, historical research, FBS/FCS treatment, and PWA.

### Pass 4: Production acceptance and closeout
- Add focused regression coverage for Games That Matter selection, CFP Top 25 comparison (including missing official releases), favorite-team persistence, and major navigation routes.
- Require passing Python tests, TypeScript/typecheck, production build, mobile browser smoke, and published-site smoke against the release commit on `main`.
- Verify the actual deployed commit, the updated homepage and CFP page, and primary mobile user journeys; document any remaining manual acceptance gaps rather than marking them passed.
- Commit final release notes and change roadmap status to COMPLETE **only after** all gates pass. No V3.4.3 work under this roadmap.

### Definitive finished product
A fan opening the mobile app sees their saved teams, useful upcoming matchups, model-supported upset alerts, and games with meaningful playoff/ranking stakes—without redundant navigation blocks. The CFP Forecast page compares the model's Top 25 against the actual dated committee Top 25, keeps the projected 12-team bracket distinct, and explains bubble/impact games. All existing analytics remain accessible and correct; missing official data is clearly identified. Tests and the deployed site are verified, and release documentation records the final commit and evidence.
