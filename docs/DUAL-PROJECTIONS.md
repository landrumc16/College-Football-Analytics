# Dual projection models: Standard and Momentum

**Status:** development on `dual-projection-development`. It is not merged and not deployed. Official forecasts still
come from the existing (incumbent) engine.

**Evidence:**
- **Results:** `research/dual/evaluation.json`, regenerated by `python -m cfb_analytics.dual_evaluation`.
- **Current projections:** `web/public/dual-projections.json`, from `python -m cfb_analytics.dual_publish`.

## The two models (`src/cfb_analytics/dual_projection.py`)

Both models share **one** opponent-strength fit. They differ only in how a team's own games are averaged.

**Stage 1 (shared):** a ridge fit of points scored:
- the formula is `points(team, game) = mean + offense(team) + defense(opponent) + home × site`, using completed games
  before the cutoff;
- it is shrunk toward preseason priors;
- FCS opponents are pooled into one team.

This is the only place opponent strength enters, so it is never counted twice.

**Stage 2 (per model):**
- **Inputs:** each team's opponent-adjusted game values, capped at ±24 points so one blowout cannot dominate.
- **Averaging:** the values are averaged with model weights and shrunk toward the team's prior, which counts as 3 games.

| Model | Weighting |
| --- | --- |
| Standard | Every completed game counts equally |
| Momentum | Stair-step weights: the newest game counts most, and each earlier game counts 10% less (geometric 0.90). Weights are rescaled to the same effective sample size as Standard |

**Preseason prior:** 0.9 × last season's final Standard rating. Programs new to FBS start at −12 points.

**Projections:**
- **Points:** home points = mean + offense(home) + defense(away) + home field, and away points are computed the same
  way from the other side. Home field is about 3.3 points in total, and there is none at neutral sites.
- **Win probability:** `1 / (1 + exp(−margin / s))`, with `s` fitted only on earlier seasons.

**Season records:** each team's actual record plus the **exact** win distribution of its remaining games under that
model's own probabilities. Records are therefore internally consistent with the game forecasts (this is tested).

**Conference, CFP and title odds:** the existing `cfp.simulate_cfp` rules, unchanged (10,000 seasons), fed each
model's ratings, home field and probability scale.

## Evaluation (`src/cfb_analytics/dual_evaluation.py`)

**Cohort:** identical FBS-vs-FBS games, 2017–2025, 6,266 games pooled. 2020 is reported but excluded from pooled
results.

**No future data:** every projection uses only games before that game's week.

**Comparison:** the existing method is replayed with last season's rating as its prior. This is a labelled
retrospective replay, not archived forecasts.

**Settings chosen before testing:** the prior settings (0.9 carry-over, 3 games) and the Momentum decay were chosen
only on 2017–2019 and 2021, then reported on held-out 2022–2025.

Each cell shows Brier score (lower is better) / winner accuracy / margin MAE.

| Games | Existing method (replay) | Standard | Momentum |
| --- | --- | --- | --- |
| 2017–2025 pooled (6,266) | 0.1834 / 71.8% / 12.85 | 0.1819 / 71.9% / 12.89 | 0.1816 / 72.0% / 12.87 |
| Weeks 1–7 (2,886) | 0.1786 / 73.3% / 12.94 | 0.1778 / 73.1% / 13.10 | 0.1774 / 73.1% / 13.08 |
| Week 8 onward (3,380) | 0.1874 / 70.4% / 12.77 | 0.1854 / 71.0% / 12.72 | 0.1851 / 71.0% / 12.68 |
| Held-out 2022–2025 (3,174) | 0.1885 / 70.8% / 12.63 | 0.1860 / 71.5% / 12.60 | 0.1853 / 71.6% / 12.59 |
| Held-out, week 8 onward (1,724) | 0.1946 / 69.1% / 12.59 | 0.1921 / 70.0% / 12.46 | 0.1912 / 70.3% / 12.44 |

### Findings

**Uncertainty:** these are 95% intervals, clustered by season and week.

- **Against the existing method:**
  - **Momentum:** better pooled; its interval for the Brier difference is [−0.0034, −0.0002], which excludes zero.
  - **Standard:** its interval is [−0.0030, +0.0001], which just includes zero.
  - **By season:** the new models are better in 2019 and in every season from 2021 to 2025, and slightly worse in
    2017–2018, when the least history was available.
- **Recent-game weighting:** it helps a little.
  - **Results:** Momentum beats Standard in the second half and on held-out seasons. Its held-out difference interval
    is [−0.0017, +0.00002], so the gain is consistent but not statistically separable.
  - **Decay strength:** the specified linear stair-step, at 0.1822 pooled and 0.1852 held-out, performs between the
    two. Stronger decays (geometric 0.80 and 0.70) were worse.
- **Calibration:** the slope is 1.02 for both new models and 0.81 for the existing-method replay, which is
  overconfident.
- **Scores:** the projected-score error is 9.4 points per team, and the projected-total error is 13.4 points.
- **Season records:** projections made from a week-8 snapshot (retrospective; 1,054 team-seasons) miss the actual
  final regular-season wins by an average of 0.946 wins for Standard, 0.943 for Momentum and 0.961 for the existing
  method.
- **Authentic 2026** (125 games with forecasts published before kickoff):

  | Forecast | Brier |
  | --- | --- |
  | Published incumbent | 0.2095 |
  | Incumbent-method replay | 0.2045 |
  | Standard | 0.2094 |
  | Momentum | 0.2080 |

  This is a small sample from one season.
- **How different the models are:** they are correlated perspectives. On upcoming games they differ by a median of 2
  percentage points (8 at most). The page explains each gap, using the team whose last three games differ most from
  its season level.

## Product (preview)

**Where it lives:** **Home → Model Projections** (`#/projections`), linked from Game Predictions. It is added from
`main.tsx`, and no protected app file changes.

**Views:**

| View | What it shows |
| --- | --- |
| Compare | Both models side by side |
| Standard | The equal-weight projection |
| Momentum | The recency-weighted projection |

**Features:**
- week and team filters;
- projected scores and win probabilities;
- the official forecast for reference;
- a plain-language disagreement explanation;
- projected records with conference and CFP odds per model;
- validation results, with the existing-method rows labelled as a replay.

**Tests:** `web/tests/model-projections.mjs` (five widths, keyboard, overflow, contrast, bottom navigation, missing
data) and `web/tests/model-projections-unit.mjs`.

**Freshness:** the dashboard build reruns `dual_publish` from the routinely refreshed CFBD snapshot. A failure keeps
the committed file and does not block deployment.

## Recommendation

1. **Ship as a clearly labelled preview** beside the official forecasts. The evidence supports it: both models are
   well calibrated and at least as accurate as the existing method on identical historical games, with a modest,
   consistent edge from week 8 onward.
2. **Do not replace the official forecasts yet.** The 2026 authentic comparison is small, and the margins are about
   1%. Revisit promotion after more authentically recorded weeks.
