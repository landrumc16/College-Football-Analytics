# College Football Analytics — Version 3.3 Roadmap

Status: **In development** on `v3.3-development`. Production `main` is the verified V3.2 release.

## Objective
Improve trustworthy out-of-sample predictive evaluation, ranking explainability and CFP forecast quality without regressing the published 2026 workbook baseline.

## Existing evidence and constraints
- V3.2 deployed successfully (GitHub Actions run 41537602629). Preserve production until release gates pass.
- V3.2's eight one-factor workbook candidates were evaluated on the same 510-game 2026 retrospective replay. None earned promotion; ridge=7 was only a research lead.
- The separate 2022–2025 Elo historical study contains a 2025 holdout and must not be used as proof that 2026 workbook settings generalize.
- Preserve 138-team frozen roster, FBS–FCS game coverage, pre-week information boundaries, and archived-vs-retrospective distinctions.
- No invented AP, Coaches or CFP rankings; explicitly label missing or unmatched polls.

## Milestones and acceptance criteria
1. **Reproducible baseline and paired evidence.** Extend the existing chronological 2022–2025 Elo research with per-season/per-matchup counts, paired candidate-vs-incumbent Brier and log-loss deltas, and calibration summaries. CI must verify identical eligible games, frozen V2 baseline parity, and no future information. Record limitations.
2. **Bounded research candidates.** Evaluate strength of schedule/opponent quality, home field, FCS handling, preseason priors and probability calibration only where source features exist at prediction time. Separate development selection from untouched holdout evaluation. No automatic promotion.
3. **Ranking explanations.** Expose reproducible drivers (record, schedule, opponents, rating context, uncertainty when measurable) with provenance; no fabricated causal attribution or model factors.
4. **Poll intelligence.** Source dated AP/Coaches/CFP snapshots, normalize schools conservatively, show coverage and unmatched names, and distinguish ranking disagreement from predictive superiority.
5. **CFP forecasting.** Evaluate conference and playoff projections against realized outcomes where archived forecast snapshots exist. Add transparent scenario explanations and tests; do not label postgame reconstructions prospective.
6. **Release.** Run Python tests, historical research checks, frontend build, mobile/browser smoke, Pages artifact validation and published-site smoke. Review and merge PR only after green checks.

## Phase 1 immediate implementation
Add deterministic paired-score research utilities to the existing V3 Elo study; validate same-game alignment, chronological split, metric reconciliation and empty/missing cases. Keep the incumbent model untouched.

## Definition of done
A reproducible, documented V3.3 research and dashboard increment, credible evaluation evidence, green CI, merged `main`, successful GitHub Pages deployment and published-site verification. A new prediction formula is optional and requires independent holdout evidence.
